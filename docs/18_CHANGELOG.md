## Versioning Policy

QuantumUI follows Semantic Versioning (MAJOR.MINOR.PATCH):

- **MAJOR** — incompatible API changes or breaking changes to the experiment data model.
- **MINOR** — backward-compatible functionality, such as a new template category, adapter, or export target.
- **PATCH** — backward-compatible bug fixes.

Every release entry should reference the relevant pull requests or issues and note any change to default behavior (for example, execution defaults, sharing defaults, or accessibility-relevant UI changes), since these carry extra scrutiny per `16_DECISIONS.md`.
